# Termit — сборки

Здесь лежат только собранные релизы Termit (приложение TermitShell для macOS).
**Исходного кода в этом репозитории нет** — разработка ведётся в закрытом репозитории на
[repobase.ru](https://repobase.ru).

## Скачать

Все версии — на вкладке [Releases](../../releases). Последняя — [Releases → Latest](../../releases/latest).

| Платформа | Файл |
|---|---|
| macOS | `Termit-<версия>-macos.zip` (+ `.sha256`) или `TermitShell.app.zip` |

Сборки не подписаны сертификатом Apple: при первом запуске — правый клик → «Открыть».
